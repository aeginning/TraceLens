# TraceLens 1.12.8 — zrzuty najważniejszych funkcji

Dziewięć oryginalnych zrzutów PNG wykonanych 11 września 2026 na telefonie Honor BVL-N49, z aplikacji 1.12.8 (kod 42). Język polski, jasny motyw, rozdzielczość każdego ekranu: 1280 × 2800 px. Zrzuty nie były retuszowane.

| Plik | Prezentowana funkcja |
| --- | --- |
| [01-biblioteka-obrazow.png](01-biblioteka-obrazow.png) | Własne obrazy, ulubione, wyszukiwanie, filtry i kolekcje. |
| [02-edytor-obrazu.png](02-edytor-obrazu.png) | Stały podgląd obrazu, gumka, kadrowanie, obrót i filtry. |
| [03-wzory-offline.png](03-wzory-offline.png) | Przeglądanie pakietu 72 gotowych wzorów bez internetu. |
| [04-podglad-wzoru.png](04-podglad-wzoru.png) | Podgląd wzoru, autor, licencja, dodanie do biblioteki lub utworzenie projektu. |
| [05-projekty.png](05-projekty.png) | Wznawianie, archiwizacja, import, eksport i transfer projektu. |
| [06-instrukcja.png](06-instrukcja.png) | Wbudowane objaśnienia kolejnych etapów pracy. |
| [07-ustawienia.png](07-ustawienia.png) | Wybór języka, motywu, podpowiedzi i ustawień domyślnych. |
| [08-tryb-rysowania.png](08-tryb-rysowania.png) | Nakładka na kamerę, przezroczystość, blokada i wskaźniki urządzenia. |

Zrzuty 08–09 pokazują aktualne otoczenie telefonu. Do materiałów promocyjnych warto ponowić je po ustawieniu telefonu nad czystą kartką. Dostępny aktywny projekt nie zawierał zdjęć postępu, dlatego nie dołączono pustej galerii.
