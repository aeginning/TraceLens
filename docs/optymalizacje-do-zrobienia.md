# Optymalizacje — temat zamknięty

Trzy pierwotnie wybrane optymalizacje zostały wdrożone:

- asynchroniczne ładowanie miniaturek i ograniczenie dekodowania pełnych bitmap w galeriach,
- lekki, opóźniony i anulowalny podgląd filtrów w edytorze,
- ograniczenie częstotliwości czujnika oraz odseparowanie jego wskazań od głównego ekranu kamery.

Pozostałe propozycje — zmiany zapisu danych, dodatkowy cache pełnych bitmap, energooszczędny timelapse, Macrobenchmark i Baseline Profile oraz dalsze zmniejszanie AAB — zostały odroczone bez planu wdrożenia.

Nie rozwijamy ich prewencyjnie. Wracamy do nich wyłącznie wtedy, gdy testy lub użytkownicy potwierdzą konkretny problem wydajnościowy.
