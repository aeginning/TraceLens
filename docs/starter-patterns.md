# TraceLens — pakiet wzorów offline

Wzory `Star`, `Heart`, `Flower` i `Butterfly` są oryginalnymi, geometrycznymi
grafikami generowanymi programowo przez kod aplikacji w pliku
`StarterPatterns.kt`. Nie wykorzystują ani nie kopiują zewnętrznych obrazów,
fontów, bibliotek grafik lub materiałów pobranych z Internetu.

Wzory są częścią kodu źródłowego TraceLens i są dystrybuowane na tych samych
warunkach co aplikacja. Dokument należy aktualizować przed dodaniem dowolnego
wzoru pochodzącego z zewnętrznego źródła. Dla takiego wzoru wymagane są:

- nazwa autora,
- bezpośredni adres źródła,
- nazwa i wersja licencji,
- data pobrania,
- potwierdzenie prawa do redystrybucji w aplikacji.
