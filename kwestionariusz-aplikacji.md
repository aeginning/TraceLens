# Planowane funkcje TraceLens

Plik zawiera wyłącznie funkcje pozostające do realizacji lub ponownego przejrzenia.

## Wersja 1.13 — bezpieczniejsza edycja obrazów

- [ ] Historia operacji **Cofnij/Ponów** w edytorze.
- [ ] Pędzel przywracający fragmenty usunięte gumką albo filtrem tła.
- [ ] Podgląd przezroczystych obszarów na szachownicy.
- [ ] Presety filtrów zapisywane pod własną nazwą.
- [ ] Import i edycja obrazów WebP.
- [ ] Import SVG z zachowaniem jakości skalowania.

## Wersja 1.14 — projekty i pełna kopia danych

- [ ] Duplikowanie projektu razem z konfiguracją obrazu i kamery.
- [ ] Wyszukiwanie projektów po nazwie.
- [ ] Sortowanie projektów według nazwy, utworzenia, modyfikacji i ostatniego użycia.
- [ ] Eksport całej biblioteki, wszystkich projektów i ustawień do jednej kopii.
- [ ] Odtwarzanie pełnej kopii danych.
- [ ] Przenoszenie kompletu danych na drugi telefon bez konta i chmury.
- [ ] Automatyczne testy migracji danych pomiędzy wersjami aplikacji.

## Wersja 1.15 — organizacja biblioteki i pozyskiwanie obrazów

- [ ] Tagi przypisywane obrazom niezależnie od kolekcji.
- [ ] Wykrywanie duplikatów podczas importowania własnych plików.
- [ ] Zaznaczanie wielu obrazów i operacje zbiorcze.
- [ ] Skróty otwierające zaufane katalogi otwartych grafik w przeglądarce.
- [ ] Gotowe zapytania wyszukiwania, np. prosty kontur lub grafika wektorowa.
- [ ] Krótka instrukcja sprawdzania autora, licencji i prawa do wykorzystania obrazu.

## Wersja 1.16 — dodatkowe narzędzia podczas rysowania

- [ ] Ręczna kompensacja ekspozycji kamery.
- [ ] Zoom cyfrowy kamery niezależny od skali nakładki.
- [ ] Zamrożenie klatki z kamery podczas precyzyjnego ustawiania nakładki.
- [ ] Zapis zdjęcia bez nakładki i z nakładką jednym poleceniem.
- [ ] Szybkie wartości przezroczystości, np. 10%, 25%, 50% i 75%.
- [ ] Lupa powiększająca fragment wskazany palcem.
- [ ] Profile pracy, np. ołówek, farby, ściana, mała kartka i duży format.
- [ ] Sygnał haptyczny po zablokowaniu nakładki albo wykonaniu zdjęcia.

## Wersja 1.17 — inteligentne pozycjonowanie

- [ ] Automatyczne wykrywanie krawędzi kartki i proponowanie czterech rogów.
- [ ] Korekcja perspektywy nakładki względem wykrytej płaszczyzny.
- [ ] Stabilizacja nakładki po niewielkim poruszeniu telefonu lub statywu.
- [ ] Opcjonalne drukowane markery stabilizacyjne w rogach kartki.
- [ ] Kalibracja rzeczywistego rozmiaru grafiki w centymetrach.

## Wersja 1.18 — dostępność, energia i jakość

- [ ] Regulacja jasności ekranu bez opuszczania projektu.
- [ ] Tryb oszczędzania energii podczas długiej pracy.
- [ ] Alternatywny rozmiar kontrolek i tekstu.
- [ ] Testy na telefonach różnych producentów, aparatach i proporcjach ekranów.
- [ ] Automatyczne testy najważniejszych ekranów i przepływów użytkownika.

## Wersja 1.19 — internetowy katalog wzorów

- [ ] Publiczny katalog wzorów na stronie TraceLens, początkowo tylko do odczytu.
- [ ] Manifest katalogu zawierający identyfikator, tytuł, plik, miniaturę, kategorię, autora i licencję.
- [ ] Pobieranie indeksu katalogu przez aplikację bez konta użytkownika.
- [ ] Lokalny cache indeksu, miniaturek i pobranych wzorów.
- [ ] Warunkowe odświeżanie katalogu przez `ETag` albo numer wersji.
- [ ] Lokalne wyszukiwanie i filtrowanie pobranego indeksu.
- [ ] Dodawanie pobranego wzoru do prywatnej biblioteki albo bezpośrednie tworzenie projektu.
- [ ] Ocena łatwości odrysowania: prosta, średnia lub szczegółowa.
- [ ] Automatyczna ocena złożoności na podstawie liczby krawędzi i kolorów.
- [ ] Podobne wzory wyliczane lokalnie na podstawie tagów.

## Wersja 1.20 — zgłaszanie wzorów przez użytkowników do ponownego przejrzenia

- [ ] Formularz zgłoszenia na stronie zamiast otwartego uploadu bezpośrednio z aplikacji.
- [ ] Jednorazowy token wysyłania wydawany przez backend.
- [ ] CAPTCHA lub Turnstile oraz limity żądań i rozmiaru plików.
- [ ] Walidacja MIME, wymiarów i rzeczywistej zawartości obrazu.
- [ ] Usuwanie EXIF i generowanie bezpiecznego pliku wynikowego po stronie serwera.
- [ ] Wykrywanie duplikatów przez hash perceptualny.
- [ ] Kolejka moderacyjna przed publicznym udostępnieniem obrazu.
- [ ] Deklaracja praw i licencji przy zgłoszeniu.
- [ ] Procedura zgłaszania naruszeń i usuwania treści.
- [ ] Lokalny identyfikator pozwalający sprawdzić status zgłoszenia bez konta.
